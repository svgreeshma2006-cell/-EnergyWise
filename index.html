🤖 Multi-Agent System

Four specialised IBM Granite-powered agents working together — each with a focused role in your energy awareness journey.

📈
Analysis Agent
Consumption Analysis Agent
Ingests hourly smart meter telemetry, detects high-load periods, baselines standby draw, and flags anomalous spikes using statistical analysis.
Capabilities:
  • Hourly consumption pattern detection
  • Anomaly spike flagging (+2σ threshold)
  • Standby / phantom load baselining
  • Peak vs off-peak load analysis
  • Month-over-month trend comparison

🎓
Education Agent
Energy Education Agent
Translates complex technical metrics into relatable daily analogies. Explains BEE Star ratings, electricity tariff slabs, and ToD pricing in plain language.
Knowledge RAG Sources:
  • BEE Star Rating database (1–5 star appliances)
  • ENERGY STAR efficiency benchmarks
  • State electricity tariff slabs (BESCOM, TATA, etc.)
  • Time-of-Day (ToD) pricing structures
  • Carbon emission factors by grid region

Savings Agent
Energy Saving Recommendation Agent
Generates targeted, prioritised cost-reduction recommendations based on your actual consumption profile — from zero-cost habits to strategic upgrades.
Recommendation Types:
  • Thermostat optimisation (24–26°C AC)
  • Peak-hour load shifting schedules
  • Phantom/standby load elimination
  • BEE 5-star appliance upgrade ROI
  • Solar PV payback analysis
IBM Granite Prompt Role: Based on the consumption report, generate 5 prioritised, actionable energy-saving tips with estimated kWh and cost savings...

Chat Agent
